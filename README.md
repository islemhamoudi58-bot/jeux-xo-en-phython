Jeu XO — Tic-Tac-Toe

Présentation

Jeu XO développé en Python avec une interface graphique Tkinter. Deux joueurs peuvent jouer à tour de rôle, suivre leurs scores et consulter leurs statistiques.

 Fonctionnalités

- Saisie des noms des deux joueurs
-  Grille de jeu interactive 3 × 3
-  Détection automatique de la victoire et du match nul
-  Gestion des scores
-  Enregistrement des parties et des statistiques avec SQLite
-  Possibilité de commencer une nouvelle partie
-  Consultation des statistiques des joueurs
-  Réinitialisation des scores de la session

 Technologies utilisées

- Python
- Tkinter — interface graphique
- SQLite — base de données
- Git et GitHub — gestion du code source



 Objectif pédagogique

Ce projet m'a permis de pratiquer la programmation orientée objet en Python, la création d'interfaces graphiques, la gestion des événements et la persistance des données avec SQLite.
